# ClipFlow — لوحة صناعة YouTube Shorts

تطبيق محلي بواجهة عربية تفتح في المتصفح. من لوحة واحدة تضيف قنوات YouTube المصرح بها، تربط قناتك، تضبط الخصوصية، وتعاين النتائج، وتشغّل خط المعالجة يدوياً أو يومياً تلقائياً.

بعد الإعداد الأولي لا تحتاج إلى PowerShell أو إدخال رابط فيديو كل يوم. افتح **Start ClipFlow.bat**؛ يفتح الموقع ويعمل النظام في الخلفية عند تسجيل الدخول إلى Windows، ثم يفحص القنوات كل 24 ساعة إلى أن تضغط **إيقاف العمل**. يستمر الفحص ما دام Windows يعمل وغير نائم.

## ما يفعله النظام

1. يفحص أحدث الفيديوهات في كل قناة، ويتجاوز المعالَج منها حتى يصل إلى 3 فيديوهات غير معالجة؛ يستمر إلى الأقدم عند الحاجة.
2. ينزّل الفيديو الأصلي مؤقتاً أثناء التحليل فقط، ثم يحذفه بعد إنتاج المقاطع أو عند فشل التنزيل. يحذف أيضاً أي تنزيل جزئي متروك عند بدء التشغيل، ويحفظ معرّف الفيديو وحالته فقط في SQLite.
3. يفرّغ الكلام محلياً باستخدام Whisper، ويبحث عن تناقضات وأسئلة وخطافات وانفعالات لفظية وكثافة الكلام والفجوات. يستخدم بطاقة NVIDIA تلقائياً إن كانت متاحة، وإلا يرجع إلى المعالج. يحلل تغير شدة الصوت محلياً إن أمكن.
4. يفحص كامل الفيديو، ويعالج حتى 3 فيديوهات غير معالجة من كل قناة في الدورة وكل الفيديوهات المعلّقة. يستهدف 5 لحظات موزعة زمنياً لكل فيديو، ويختار مدة متغيرة حسب اكتمال الفكرة وكثافة الكلام؛ عادةً 8–30 ثانية، وحتى 45 ثانية للقصة السريعة المتصلة.
5. يستبعد الفجوات الطويلة وينهي المقطع عند نهاية جملة أو وقفة طبيعية. يحرق الكلام المنطوق باللغة الأصلية في مجموعات قصيرة ثابتة الموضع مع تمييز الكلمة الحالية، بلا تكبير نابض، ويحافظ على الإطار الأفقي كاملاً فوق خلفية مطموسة.
6. تعرض المكتبة الخطاف والتوقيت وسبب الاختيار والحركة البصرية المقترحة والنص والكابتشن.
7. يولّد عنواناً قصيراً وسؤال تفاعل ووسوماً مرتبطة بالنص. ينشر حتى 3 مقاطع كل 24 ساعة بفاصل ساعتين، ويخصص كل فترة 24 ساعة لمصدر واحد بالتناوب (يبدأ بسبيد)، ثم يرفعها إلى YouTube عبر OAuth الرسمي.

الاختيار آلي ومبني على النص ومؤشرات الصوت؛ لا يفحص تعابير الوجه أو يضمن الانتشار. الحركة البصرية المعروضة اقتراح للمونتاج. الوسوم مرتبطة بالموضوع ووسم Shorts، ولا تدّعي أنها ترند لحظي.

## الإعداد الأولي على Windows

### 1. تثبيت المتطلبات

- ثبّت Python 3.11 أو أحدث.
- ثبّت FFmpeg وFFprobe وأضف مجلدهما إلى `PATH`.
- فك ضغط المشروع، ثم انقر مرتين على `install_windows.bat` وانتظر اكتمال تثبيت المكتبات.

### 2. إضافة القنوات

افتح لوحة ClipFlow وأضف اسم ورابط كل قناة. فعّل مربع تأكيد الملكية أو الإذن قبل إضافتها. لا ينزّل النظام قناة ما لم تكن مضافة ومصرحاً بها.

### 3. ربط قناة YouTube للنشر

1. سجّل الدخول إلى [Google Cloud Console](https://console.cloud.google.com/apis/credentials) بحساب Google الذي يملك قناة YouTube، وأنشئ مشروعاً.
2. فعّل **YouTube Data API v3** من API Library.
3. من **Credentials / بيانات الاعتماد** اختر **Create credentials → OAuth client ID**، وحدد نوع التطبيق **Desktop app** ثم أنشئ العميل ونزّل ملف JSON.
4. إذا طلب Google إعداد شاشة موافقة OAuth، أكملها وأضف بريدك كـ **Test user** عندما يكون التطبيق بوضع الاختبار.
5. ارفع الملف الذي اسمه عادةً `client_secret_....json` من بطاقة **بيانات Google OAuth** في اللوحة، ثم اضغط **ربط حساب YouTube** واختر القناة ووافق على صلاحية الرفع.

هذا الملف ليس رابط فيديو ولا API key. يُحفظ محلياً على الجهاز؛ بعد الربط يُخزّن رمز OAuth محلياً ويُجدّد عند الحاجة.

يمكن ضبط النشر تلقائياً أو إيقافه، واختيار خصوصية **عام** أو **غير مدرج** أو **خاص** من الإعدادات. الوضع الافتراضي عام.

## التشغيل اليومي

- انقر مرتين على `Start ClipFlow.bat`.
- تفتح الواجهة على `http://127.0.0.1:5000`.
- اضغط **تشغيل الآن** لإجراء فوري، أو اترك التشغيل اليومي مفعلاً.
- للبدء مع Windows، أضف `Start ClipFlow.bat` إلى مجلد Startup أو Windows Task Scheduler مرة واحدة.
- لإيقاف التطبيق، أغلق نافذة التشغيل.

## الملفات

- `web_app.py` و`templates/` و`static/`: الموقع والواجهة.
- `youtube_monitor.py`: مراقبة القنوات والتنزيل.
- `opus_automation.py`: تجهيز المقاطع والكابتشن باللغة المنطوقة محلياً بـ FFmpeg وWhisper.
- `caption_generator.py`: العناوين والوسوم.
- `auto_uploader.py`: تفويض YouTube والرفع.
- `database.py`: سجل الفيديوهات والمقاطع والنشر.
- `downloads/clips/`: المقاطع النهائية. مجلد المصادر مؤقت ويُفرّغ بعد المعالجة.
- `data/`: قاعدة البيانات وملف OAuth الخاص.
- `logs/pipeline.log`: سجل التشغيل والأخطاء.

## ملاحظات

- استخدم فقط فيديوهات تملكها أو لديك إذن بتنزيلها وتعديلها وإعادة نشرها.
- الموقع مربوط إلى `127.0.0.1` ويعمل على جهازك فقط؛ لا تفتحه للإنترنت العام.
- لا يدوّر التطبيق حسابات لتجاوز حدود المنصات. الحد الافتراضي 3 منشورات يومياً.
- معالجة الفيديوهات تتطلب FFmpeg، وأول تشغيل ينزّل نموذج Whisper، لذلك قد يستغرق وقتاً أطول.
- يحتاج الفيديو الأصلي إلى مساحة مؤقتة أثناء المعالجة، ثم يُحذف آلياً. إذا كان المطلوب ألا يُنزّل الأصل إلى جهازك إطلاقاً، يجب تشغيل خط المعالجة على خادم سحابي؛ مجرد حفظه في Google Drive لا ينقل المعالجة عن جهازك.
- الحسابات والرموز تحفظ محلياً في `data/`؛ لا تشارك هذا المجلد ولا ترفعه إلى Git.
